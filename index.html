6-Part Comprehensive Report

การศึกษาเปรียบเทียบ
Zero-shot vs Refined Prompting

รวบรวมและสรุปผลการประยุกต์ใช้ Prompt Engineering สำหรับงานวิศวกรรมและงานวิชาการ ครอบคลุมทั้ง 6 โดเมนหลัก

01. Image Gen

Visual Creation

DALL-E / Midjourney

Zero-shot ภาพที่ได้ขาดรายละเอียด ทรงพลังน้อย และปรับมุมกล้องไม่ได้
Refined Prompt กำหนด Style, Lighting, Composition และ Camera Angle ชัดเจน
02. Math Visualization

Interactive Pulsing Heart

Desmos Calculator

Zero-shot ได้สมการหัวใจแบบสถิต (Static) อยู่นิ่งๆ ไม่ขยับ
Refined Prompt ใช้ Slider Parameter t ควบคุมการยืด-หดขยายตัว (Pulsing Heartbeat)
03. Diagramming

User Registration Sequence

Mermaid.js

Zero-shot ได้ผังงาน Flowchart เส้นตรงง่ายๆ ไม่เห็น Interaction
Refined Prompt สร้าง Sequence Diagram แบ่ง Actors (FE, BE, DB) พร้อม Alt Block เช็ค Error
04. Academic Writing

21 Laws of Leadership Paper

Overleaf (LaTeX)

Zero-shot ได้ข้อความพื้นฐาน ขาด Document Class และ Packages
Refined Prompt จัดรูปแบบ IEEE Format 2 Columns พร้อมสมการ Law of the Lid & ตาราง
05. Content Summarization

Slide Deck Extraction

NotebookLM

Zero-shot ได้ย่อหน้ารวมเนื้อหายาวพืด (Paragraph Summary)
Refined Prompt สกัดเป็นโครงร่าง 5 สไลด์ พร้อม Bullet Points และ Speaker Notes
06. Web Portfolio

Single-File Web Deployment

GitHub Pages

Zero-shot ได้ HTML เปลือยๆ ตัวอักษรสีดำบนพื้นขาว ไม่มีความสวยงาม
Refined Prompt ได้เว็บ Modern Dark Tone มี Responsive Grid พร้อม Publish บน GitHub Pages
